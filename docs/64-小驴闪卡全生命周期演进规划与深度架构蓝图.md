## 二、 演进路线规划（R55 ~ R58 分期演进）

### 第一期 (R55 · 当前执行)：核心体验质变
- **RemNote 阶梯式列表逐项展开卡**：敲空格逐步揭晓多要点，骨架引导回忆，支持逐项 `✔/✘` 打标；
- **Obsidian SR 风格整篇文档间隔温故**：文档根块打标进入温故流，全幅长文画布 + 悬浮吸顶/吸底 FSRS 打分栏；
- **RemNote 级大纲层级语境面包屑**：双通道推导（内核 API 优先 + 单调栈兜底），精准还原 `文档 ❯ 章节 ❯ 要点`。

---

### 第二期 (R56)：高级题型与动态队列

#### 1. 图片高级遮挡 2.0（Image Occlusion 2.0）
- **核心模式**：
  - **Hide All, Guess One（全遮猜一，防剧透）**：全图标注全部磨砂覆盖，当前测试框高亮发光（Golden Amber），防止周边文字提示答案；
  - **Hide One, Guess One（单遮猜一）**：保留周边作为线索；
  - **Tap to Peek（点击任意遮罩即时透视）**：轻触或悬浮任意遮罩单独透视，松手恢复，便于邻近结构比对；
  - **遮挡就地填空（Occlusion Typing）**：在遮罩槽位内就地打字核对拼写。

#### 2. 正反双向卡（Bidirectional Cards）+ 跨天兄弟卡真埋藏（True Sibling Burying）
- **规约**：单卡标记 `custom-lv-bidirectional: "true"` 或 `Front ::: Back`，自动派生双向考核；
- **真埋藏机制**：今日复习了正面（A -> B），系统自动将反面（B -> A）**埋藏至次日（Buried Until Tomorrow）**，杜绝瞬时工作记忆作弊。

#### 3. 智能动态过滤牌组（Smart Dynamic Filtered Decks）
- **规约**：支持用户保存自定义规则组合（例如：`错题 >= 2次` + `标签:#高频考点` + `超期 > 7天`）；
- 点击一键生成**临时虚拟复习集**，不改变卡片物理卡包，复习评分直接回写主数据，刷完即走。

---

### 第三期 (R57)：生态协同与深度内化

#### 1. 文档内伴生微复习浮窗（In-Doc Floating Review）
- 打开包含闪卡的文档时，右上角常驻轻量呼吸徽章：`✦ 本文档有 4 张待复习`；
- 点击在文档右侧滑出 360px 伴生抽屉，就地自测，答完即收，呵护阅读心流。

#### 2. 表格对比闪卡（Table Flashcards）
- 支持思源原生 Markdown 表格：
  - **整列遮挡**：遮挡某一属性列（如“时间复杂度”、“不良反应”），逐行回忆比对；
  - **交叉网格抽查**：给出某行表头 + 某列表头，抽查交叉单元格。

#### 3. 增量阅读（Incremental Reading, IR）全闭环
- 长篇论文/技术专著加入渐进阅读池 -> 粗读时划取核心段落（Extracts）-> 摘录到期再重读并转化为原子闪卡 -> 解散（Dismiss）原摘录。

---

### 第四期 (R58)：认知科学与算法深水区

#### 1. 纯本地 FSRS-4.5 个人复习历史权重自适应拟合（Personalized FSRS Weight Optimizer）
- 利用本地 `revlog.json` 累积的 1000+ 条真实复习数据；
- 在纯前端 Web Worker 中运行梯度下降与对数似然评估算法，计算出最适合用户大脑特性的 17 个个性化 FSRS 权重，取代通用预设。

#### 2. 负荷预测与抗滚雪球熔断（Load Relief / Holiday Mode）
- **负荷预测**：可视化推演未来 30 天每日复习卡量波峰；
- **度假模式（Holiday Mode）**：因出差、生病或放假暂停复习数天后，系统自动平摊逾期积压，防止“打开软件看到 500 张卡直接弃坑”。

## 三、 全家桶跨插件生态协同协议（Ecosystem Federation Deep-Dive）

小驴全生态（8 大插件）共享统一事件总线（`ecosystem-bridge-kit.ts`），小驴闪卡作为生态中枢与各插件深度互联：

### 1. 协同《小驴拾遗》（siyuan-glean）：增量阅读与渐进摘录
- **场景**：用户在《小驴拾遗》中剪藏了一篇万字行业深度报告；
- **协议联动**：
  1. 拾遗中点击“推送至闪卡温故”，小驴闪卡接收并在文档根块注入 `custom-lv-note-review: "true"`；
  2. 拾遗划选的金句通过 `CARDS_INCREMENTAL_EXTRACT` 事件投递至小驴闪卡材料收件箱（`inbox.json`），带完整的原文溯源反链；
  3. 用户在闪卡中将摘录加工为原子卡后，反向通知拾遗该条剪藏已消化完毕。

### 2. 协同《小驴考试》（siyuan-exam）：错题靶向回流与变式复训
- **场景**：用户在《小驴考试》模拟考场中做错了一道单选题或多选题；
- **协议联动**：
  1. 考试结束触发 `EXAM_SESSION_ENDED` 与 `EXAM_WRONGBOOK_CHANGED`；
  2. 小驴闪卡自动识别错题本变动，在卡库中生成带有 `#考试错题` 标签的专项卡片，直接纳入 FSRS 艾宾浩斯复训排期；
  3. 闪卡中该卡片连续 3 次答对后，自动将状态回流至小驴考试，将错题降级为“已攻克”。

### 3. 协同《小驴雷切》（siyuan-speed-switch）：双文档分栏对照复习
- **场景**：复习复杂的架构设计或双语翻译卡片时，需要深入比对多篇参考文档；
- **协议联动**：
  - 在闪卡复习界面按快捷键 `Alt+R`，直接唤起小驴雷切的分栏分屏，左侧保持闪卡自测，右侧自动打开当前卡片所属的思源原文档进行沉浸对照。

### 4. 协同《小驴打卡》（siyuan-checkin）：复习成果自动计入人生热力图
- **协议联动**：
  - 每次完成一场闪卡复习或整篇文档温故，小驴闪卡通过 `CHECKIN_RECORDED` 事件向小驴打卡广播学习量；
  - 小驴打卡的多维热力图自动点亮“今日深度思考与记忆”格点，形成自驱学习正反馈。

## 四、 底层工程高可用与性能护城河（Deep Architectural Resilience）

### 1. 百万级块海量卡片分级缓存（Tiered Cache & Precision Invalidation）
针对思源笔记本中拥有 50,000+ 块的重度知识库：
- **L1 内存热缓存（LRU In-Memory）**：
  - 缓存当前会话最近 500 张卡片的完整卡面 DOM 与大纲路径链条，命中耗时 0ms；
- **L2 索引持久化（IndexedDB / Storage）**：
  - 维护 `due-cache.json`，存储卡片 ID、所属文档、到期时间戳与属性摘要；
- **精准局部失效协议（Precision Invalidation）**：
  - 监听思源 WebSocket 块更新事件；
  - 仅当事件中的 `root_id` 匹配时，使对应文档的大纲与卡面缓存失效，绝不进行全库颠簸刷新。

### 2. 属性写操作防并发与单飞合并机制（Mutation Coalescing Queue）
- **问题**：在快速刷题（连续按 1/2/3/4）或连续标记列表项对错时，高频向思源发送 `/api/attr/setBlockAttrs` 会导致内核文件锁竞争（File Lock Contention）；
- **方案**：构建**属性合并写入队列（Mutation Coalescing Queue）**：
  - 采用 **Single-Flight + 300ms 防抖合并**：在 300ms 窗口期内，对同一块的多次属性写入在前端合并为最终 patch 对象，单次网络调用落盘；
  - 保证界面丝滑响应，后台绝对防锁。

### 3. 移动端全天候鲁棒性守卫（Mobile Reliability Shield）
- **切后台与息屏保护**：
  - 监听 `document.visibilitychange`：切到后台或锁屏时，自动暂停答题计时器与语音朗读；切回前台时无损恢复现场；
- **触控震动反馈（Haptic Engine）**：
  - 移动端点击阶梯展开或评分时，调用 `navigator.vibrate?.([10])` 产生 10ms 细腻微触感反馈；
- **软键盘与可视区适配（VisualViewport Guard）**：
  - 监听 `window.visualViewport?.addEventListener("resize", ...)`；
  - 当软键盘弹起时，底部悬浮操作条自动上浮避让，防止输入焦点被遮挡。
