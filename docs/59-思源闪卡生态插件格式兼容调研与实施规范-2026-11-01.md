## 一、调研背景与生态全景

在思源笔记知识管理生态中，间隔重复闪卡经历了从官方内核原生支持到社区插件多样化探索的发展历程。用户在使用小驴闪卡前，往往在知识库中遗留了大量来自官方本体或其他插件的卡片资产。为了达成**“完全无损、无缝兼容、开箱即用”**的目标，小驴闪卡对官方内核及市面上所有主流闪卡插件进行了底层格式逆向与协议对齐。

### 生态主要插件与系统概览

| 系统 / 插件名称 | 核心特征与机制 | 底层属性与语法格式 |
|---|---|---|
| **思源笔记官方本体 (Riff)** | 内核级 FSRS/SM-2 算法，基于块属性管理卡包与到期时间 | `custom-riff-decks="d1,d2"`（逗号分隔）、`==挖空==`、`memo` 块备注（无挖空时做背面答案）、超级块 `{{{col` |
| **SiYuanMemo (间隔重复系统)** | RemNote 风格 CDF (概念描述符框架) 制卡 | 概念卡 `概念 :: 定义`、属性卡 `属性 ::: 详情`、`Q: / A:`、块属性 `custom-flashcard-deck` |

## 二、思源笔记本体闪卡底层数据契约

通过对思源内核官方源码（`kernel/model/flashcard.go`）的审阅，确认以下核心底层机制：

1. **多卡包映射字段 (`NodeAttrRiffDecks`)**：
   - 内核块属性键名为 `custom-riff-decks`。
   - 存储形式为**英文逗号分隔的卡包 ID 列表**（如 `custom-riff-decks="20230218211946-2kw8jgx,deck-xyz"`）。
   - 一个块可以同时归属于多个独立卡包，内核在 `addFlashcards` 和 `removeFlashcards` 事务中进行原子列表维护。
2. **思源默认内置卡包**：
   - 默认内置卡包 ID 恒为 `20230218211946-2kw8jgx`。
   - 当用户在思源右键菜单未选择具体卡包直接点击“制卡”时，自动落入此默认卡包。
3. **答案回落策略 (`memo`)**：
   - 当块内不包含 `==...==` 挖空标记时，思源官方渲染引擎会将块的 `memo`（块备注）作为背面答案；若既无挖空也无 `memo`，则整块作为回忆面，翻面后自评。
4. **超级块与层级问答**：
   - 包含 `NodeSuperBlock`（如 `{{{col` 列超级块）时，第 1 个子块作为正面题面，后续所有子块作为背面答案。
   - 列表项与标题块的子块可作为答案展开。

## 三、小驴闪卡在底层实现的高保真兼容方案

小驴闪卡采用“纯运行时动态遮罩 + 双向非破坏性解析”架构，在彻底兼容上述所有格式的同时，**绝不擅自修改用户笔记正文**：

### 1. 语法格式兼容解析与运行时内存遮罩 (`src/core/delimited-qa.ts`)
- **概念卡与描述符卡**：精准解析 `::`（双冒号）与 `:::`（三冒号），严格利用正向/反向环视排除 C++（`std::vector`）等代码命名空间；
- **问答卡与破折号卡**：支持 `Q: ... \nA: ...`、`问：... \n答：...` 以及中文笔记常用的 `——` 单行破折号；
- **填空与下划线**：运行时自动将 `_{3,}`（连续 3 个以上下划线）识别为可点击揭晓的交互填空槽；
- **Anki Cloze 深度兼容**：新增支持 `{{c1::答案}}` 与 `{{c1::答案::提示}}` 语法，复习时就地生成带提示词的遮罩槽，维护中心提供一键规范化升级为 `==答案==`。

### 2. 闪卡工具箱自定义题面标题兼容 (`src/core/card-face.ts` & `ReviewCardBody.svelte`)
- 解析块属性中的 `custom-riff-title` 与 `custom-card-title`；
- 在复习卡面上方以精致的长春花目标徽章呈现自定义题面，保留原笔记复杂排版的同时突出核心提问。

### 3. 全景存量卡包发现与同步引擎 (`src/core/deck-management.ts`)
- **全生态属性扫描**：自动通过 SQL 检索 `custom-riff-decks`、`custom-flashcard-deck`、`custom-deck`、`custom-card-deck`、`custom-card-group`、`custom-card-pack` 等第三方插件属性；
- **标签卡包提取**：自动检索正文中的 `#deck/名称`、`#卡包/名称`、`#卡组/名称`；
- **孤儿闪卡发现**：自动捕获正文中带有 `==挖空==` 但尚未绑定任何卡包的存量闪卡；
- **思源内置卡包识别**：准确识别官方默认卡包 `20230218211946-2kw8jgx` 并冠以友好名称；
- **一键无损同步**：提供“一键全部接入”功能，将扫描到的块批量调用 `addRiffCards` 绑定到原生 RiffDeck 中，使存量卡片即刻受控于 FSRS 间隔重复算法，零数据丢失。

## 四、卡包全生命周期管理实施规范 (`src/ui/deck-manager.svelte`)

在卡库主页面的二级导航常驻“卡包管理”专属控制台：
1. **全局指标大盘**：直观展示卡包总数、闪卡总量与待接入存量卡包数；
2. **分类与搜索过滤器**：支持“全部”、“活跃卡包”、“空卡包”与“待接入存量”四大维度快速过滤与名称实时检索；
3. **卡包高级动作**：
   - 🚀 **正式复习与突击练习**：独立按卡包开启 FSRS 正式调度或考前 Cram 快刷；
   - ✏️ **重命名**：同步调用内核 `renameRiffDeck`；
   - 🔀 **卡包合并**：支持将源卡包卡片全部转移至目标卡包，避免碎小卡包泛滥；
   - 🧹 **清理空卡包**：一键安全清理卡片数为 0 的废弃卡包；
   - 🗑️ **安全删除**：明确提示“仅解散卡包，原笔记中的卡片块完整保留在正文中”，杜绝误伤笔记。
