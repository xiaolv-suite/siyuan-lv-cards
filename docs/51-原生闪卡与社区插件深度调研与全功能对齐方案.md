## 一、 调研背景与使命目标

在笔记软件与记忆算法的演进过程中，闪卡系统已从单纯的“正面问题-背面答案”卡片翻转，发展为涵盖知识捕获、渐进提炼、多题型交互、智能调度与生态联动的完整知识生命周期平台。

本调研针对用户核心反馈：
1. **超级块卡片（SuperBlock）问答识别对齐**：思源原生超级块以首块为正面、后续所有块为背面的标准语义必须 100% 保真支持；
2. **SVG / Excalidraw 矢量画布的原生编辑体验**：不能仅作为静态图片展示，必须打通思源原生编辑通道；
3. **全面对齐思源原生闪卡复习界面功能**，并系统汲取思源社区优质插件（如闪卡小助手 ZY）与行业顶级产品（Anki、RemNote、SuperMemo、Readwise）的精髓特性。

## 三、 社区与行业顶级工具优秀特性汲取与融合

```
┌────────────────────────────────────────────────────────────────────────┐
│                        全生态优秀闪卡特性蒸馏漏斗                        │
├───────────────────┬───────────────────┬────────────────────────────────┤
│ 来源体系           │ 汲取的核心精髓     │ 小驴闪卡落地映射               │
├───────────────────┼───────────────────┼────────────────────────────────┤
│ 思源闪卡小助手(ZY) │ 面包屑回源、撤销   │ review-breadcrumbs & undo栈    │
│ RemNote           │ 概念卡双冒号 ::    │ delimited-qa 智能解析          │
│ Anki              │ 兄弟卡防剧透推迟   │ filterBurySiblings 算法        │
│ Anki              │ 分级提示阶梯       │ deriveHintLevels 阶梯递进      │

└───────────────────┴───────────────────┴────────────────────────────────┘
```

### 3.1 汲取自思源社区闪卡小助手（ZY）
1. **来源文档面包屑层级直达（Breadcrumb Context）**：
   - 在复习卡片顶部呈现 `笔记本 › 文件夹 › 文档标题`，点击面包屑一秒滑出前后上下文块，让孤立的知识点瞬间回归原始笔记语境；
2. **评分撤销历史栈（Undo Review）**：
   - 错按评分键后支持按 `p` / `q` 或点击撤销按钮一键回退上一步，避免手滑造成遗忘曲线参数失真；
3. **SVG/Excalidraw 画布的原位编辑与直通**：
   - 双击画布或点击操作胶囊，自动调用 `openTab` 定位到画布原块，兼顾复习端沉浸感与编辑端生产力。

### 3.2 汲取自 RemNote 闪卡体系
1. **自然语言分隔符概念卡（Concept Cards）**：
   - 支持笔记正文中的 `概念 :: 释义` 与 `属性 ::: 描述`，即使不使用思源的 `==` 高亮，也能自然转化为闪卡；
   - 严格排除 C++ 命名空间（如 `std::vector`），防止代码误识别。

### 3.3 汲取自 Anki 核心人机工效
1. **同源兄弟卡推迟（Bury Siblings）**：
   - 一篇笔记提炼出的多个挖空或双向卡片，在同一复习会话中优先只出 1 空，自动将兄弟卡推迟到次日，杜绝即时互为线索导致“虚假记忆”；
2. **分级提示阶梯（Hint Ladder）**：
   - 按 `h` 键可逐步揭晓提示（从首字母、词长、上下文线索到完整提示），训练“主动提取”能力；
3. **打字与拼写精准判分（Typing Comparison）**：
   - 提供输入框敲入答案，自动进行逐字符差异高亮（绿色正确、红色缺失/多余），并给出智能推荐评分。

### 3.4 汲取自 SuperMemo / Readwise 渐进学习体系
1. **两级调度物理隔离（Two-Tier Schedulers）**：
   - 严禁将大段粗糙摘录卡直接扔进 FSRS 算法；摘录卡走轻量轮转队列，只有提炼为原子问答/挖空后才进入正式排期；
2. **Dismiss 解散归档机制（Ctrl+D）**：
   - 提炼出原子卡后，按快捷键 `Ctrl+D` 一键解散归档该摘录卡，彻底移出日常复习队列，保留血缘反链但不再打扰用户；
3. **最小信息过载警示（Minimum Information Principle）**：
   - 单卡字数 > 250 或挖空 > 3 时温和提示拆分，避免知识负荷过载。

## 四、 小驴闪卡独有的高维进化护城河

除完全覆盖思源原生功能与融合上述社区优点外，小驴闪卡具备 4 项领先能力：
1. **标量数值答案政策引擎**：自动换算物理量国际单位（如 `1.5km` ↔ `1500m`）与百分数容差，理科公式答案判定零误判；
2. **演示私密模式（Presentation Privacy）**：一键隐藏卡片内部隐私信息与文档敏感标题，满足投屏与教学直播诉求；
3. **可控且可审计的 AI 制卡流水线**：双 Provider 回退、Preflight 预检确认、断言事实依据对齐核验与 Token 成本硬上限；
4. **Bento 矢量美学与全令牌设计系统**：设计令牌覆盖率达 92.2%，图层 z-index 100% 满分收敛，视觉质感与思源原生主题深度契合。
