## 一、 功能层融合与状态冲突消解

### 1. 阶梯列表卡与打字默写（Typing Test）的融合
- **冲突点**：打字默写模式期望唯一的全局 `expectedText`；若直接挂在阶梯列表卡上，会导致用户不知该默写题干还是全部列表。
- **消解规则**：
  - **默认策略（分步回忆优先）**：遇到 `isSequenceCard === true` 时，`ReviewAnswerSection` 自动静默外层大段打字输入框，退回为纯键盘空格/轻触步进推进；
  - **高级逐项拼写策略（可选设置）**：若用户在设置中开启“阶梯逐项拼写”，输入框只挂在当前处于 `active` 状态的这一项阶梯槽内；输入正确按回车，自动揭晓并流转到下一项。

### 2. 阶梯列表卡与阶梯提示支架（Hint Ladder, `H` 键）的融合
- **消解规则**：
  - 阶梯列表卡的“条目总数与占位骨架”天然已构成第一级回忆脚手架；
  - 当在阶梯卡上按下快捷键 `H` 时：
    - **第 1 次按 H**：在当前 `active` 槽位呈现首字提示（如：`提示：以“进...”开头`）；
    - **第 2 次按 H**：呈现字符数与关键词提示（如：`提示：共 6 个字，包含“调度”`）；
    - **第 3 次按 H**：直接揭晓当前条目（等同于敲空格）。

### 3. 阶梯列表卡与遗忘卡同场内循环（Requeue）的融合
- **痛点**：一张包含 5 点要点的阶梯卡，若用户只漏了第 3 点，同场数分钟后重现时如果要求用户从第 1 点全部重新展开，会引发极大的挫败感与机械枯燥感。
- **智能靶向再现（Targeted Requeue）**：
  - 用户在第 1 轮作答时，通过每行右侧的 `✔/✘` 打标或漏背统计，记录了具体错误条目索引集合 `failedIndices: number[]`；
  - 在同场 Requeue 重现该卡时：
    - 顶部标注微标：`[🔥 错项靶向巩固]`；
    - 系统自动将此前已答对的条目以轻灰色弱化展示，光标与呼吸光环**直接锁定在之前答错的那几项**上，实施精准定点强化，答对后彻底归档！

### 4. 文档温故流与水蛭卡熔断（Leech）及错因标签的融合
- **消解规则**：
  - **水蛭卡隔离**：整篇文档温故走独立的文档排期逻辑，**严禁被计入 8 次遗忘水蛭卡熔断队列**（长篇大纲温故允许多次重读巩固，熔断机制仅针对原子碎片卡）；
  - **错因标签适配**：长文通读后若评为 1（Again）或 2（Hard），底部错因标签栏自动切换为文档专用标签组：`[篇幅过长需拆解] / [概念生疏需精读] / [排版杂乱需重构]`，方便后续在卡库中针对性治理。

## 二、 UI 视觉层融合与响应式排版规约

### 1. 阶梯展开卡动态高度防抖（Zero Cumulative Layout Shift）
- **现象**：敲空格每揭开一项，若页面高度向下撑大一段，会导致底部评分区和滚动条剧烈跳动，破坏视觉稳定性。
- **防抖规范**：
  - 在卡片初始化时，预先计算列表总高度：
    ```scss
    .lv-sequence-list {
        min-height: calc(var(--seq-total-items, 3) * 48px + 16px);
    }
    ```
  - 未揭晓项全部以固定高度（`min-height: 44px`）的等高磨砂骨架槽（Skeleton Bar）占据空间；
  - 推进揭晓时，槽位内部仅执行 `opacity: 0 -> 1` 与微光动画，**卡片整体包围盒几何尺寸严格保持零跳动**！

### 2. 全幅文档温故画布的排他性视口层叠
- 当当前复习项为文档温故（`isDocumentReview === true`）时，`review.svelte` 执行**排他性视口切换**：
  - **完全静默外层卡片级元素**：
    - 隐藏卡片外框 `.lv-card` 与背景白板；
    - 隐藏题面徽章 `.lv-riff-title-badge`；
    - 隐藏普通卡片底部评分栏 `ReviewRatingBar`；
    - 隐藏打字输入区与选择题题板；
  - **激活全幅阅读画布 `ReviewDocumentCanvas.svelte`**：
    - 桌面端：居中 `max-width: 900px` 呼吸阅读视口，满高纵向滚动；
    - 移动端：`100vw` 满幅，去除所有外边距；
    - 操作栏采用**玻璃拟态悬浮吸顶（桌面） / 贴底安全区（移动端）**，与长文内容物理分层（`z-index: 50`）。

### 3. 大纲语境面包屑在多层顶栏中的空间避让
- 移动端（390×844）视口空间极度宝贵。
- 面包屑与顶部导航、会话计时器并存时的层叠避让规则：
  - 视口宽度 ≤ 680px 时，顶部计时器自动折叠为小图标；
  - 大纲面包屑强制单行溢出省略（`text-overflow: ellipsis; white-space: nowrap;`），最多显示末级 2 个节点；
  - 保证大纲路径既清晰可见，又绝不把正文往下推挤。

## 三、 交互与全局快捷键仲裁状态机（Arbiter Matrix）

所有键盘事件由 `review.svelte` 统一拦截，并按以下严格的优先级仲裁矩阵进行路由分发：

```text
[按键事件到达] 
  │
  ├── 1. 输入法合成期守卫 (e.isComposing || keyCode === 229) ──> [直接放行，零干扰]
  ├── 2. 输入框焦点守卫 (activeElement 为 input/textarea) ──────> [仅响应 Esc/回车提交，屏蔽空格]
  ├── 3. 模态弹窗拦截 (Memo编辑 / 暂停弹窗 / 退出确认) ────────> [路由至对应 Modal 处理]
  └── 4. 核心复习状态机仲裁：
```

| 快捷键 | 普通问答/挖空卡（问题态） | 普通卡（答案态） | 阶梯列表卡（逐项展开中） | 阶梯列表卡（全揭晓后） | 全幅文档温故视图 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **`Space` / `Enter`** | 翻面，揭晓答案 | *(无动作或保留)* | **推进揭晓下一项** | 默认评分 Good（激活下一张） | 向下平滑滚动一屏（PageDown） |
| **`Shift + Space`** | 一键直接翻面 | *(无动作)* | **跳过逐行，直接全揭晓** | *(无动作)* | 向上滚动一屏（PageUp） |
| **`1` / `2` / `3` / `4`** | **严格禁用（防误触跳卡）** | **执行 FSRS 评分** | **严格禁用（严防未看完误评）** | **执行 FSRS 评分** | **即刻执行文档温故评分并切下一篇** |
| **`H`** | 渐进展开提示支架 | 查看 Memo 助记备注 | 展开当前条目首字/字数线索 | 查看 Memo 备注 | 唤出文档大纲目录树抽屉（TOC） |
| **`C`** | 滑出原笔记前后文抽屉 | 滑出原笔记前后文抽屉 | 滑出原笔记前后文抽屉 | 滑出原笔记前后文抽屉 | 原位高亮跳转回思源主编辑器 |
| **`M`** | 弹出 Memo 助记便签录入 | 弹出 Memo 助记便签录入 | 弹出 Memo，回写至列表父块备注 | 弹出 Memo 录入 | 弹出文档级温故总结与阅读心得弹窗 |
| **`Z`** | 撤销上一次评分 | 撤销上一次评分 | **重置当前卡回退至第 1 项** | 撤销上一次评分 | 撤销上一次文档温故评分并回滚排期 |
| **`S`** | 今日挂起当前卡片 | 今日挂起当前卡片 | 今日挂起当前卡片 | 今日挂起当前卡片 | 今日暂缓温故本文档（顺延至明天） |

## 四、 全系统生命周期联动（Cross-Module Linkage）

### 1. 卡片库（Library / Manager）检索与详情抽屉融合
- **多维筛选器扩展**：
  - 在卡型下拉菜单中增加两项原生过滤选项：
    - `📋 阶梯列表 (sequence)`
    - `📄 文档温故 (doc-review)`
- **列表项与详情抽屉表现**：
  - 阶梯列表卡：列表项 meta 区域渲染 `[阶梯列表 · N 项]` 徽章；点击卡片滑出详情抽屉时，抽屉内支持**直接交互式点击测试逐项展开**，无需进入复习即可试题；
  - 文档温故：展示 `[文档温故 · 下次复习 X天后 · 轮次 Y]` 徽章；详情抽屉提供「即刻通读」、「修改复习间隔」、「移出温故流」快捷动作。

### 2. 制卡工作台（Studio Workbench）手工模板与实时预览融合
- **手工制卡新增「阶梯列表模板」**：
  - 界面提供：
    1. 题干输入框（如：“请列举敏捷开发的 4 大核心价值观”）；
    2. 动态要点列表项（支持拖拽排序、按 Enter 自动新增一行、点击末尾垃圾桶删除）；
  - 右侧提供**实时卡面模拟器**，可就地按下空格验证阶梯推进交互；
  - 点击“存入闪卡”，后端自动生成思源列表块并写入 `custom-lv-card-type: "sequence"`。

### 3. 今日学习看板（Today Dashboard）多轨进度环融合
- 在 `dashboard.svelte`（今日学习）中：
  - 统计卡片划分为双轨展示：
    - `⚡ 待复习闪卡: 28 张`
    - `📄 待温故文档: 3 篇`
  - 启动复习按钮支持分流下拉：
    - `[开始全量复习 (推荐)]`
    - `[仅复习碎片闪卡]`
    - `[仅温故整篇文档]`

### 4. 数据导入导出（Anki / Obsidian SR / .lvcards）无损兼容
- **导出至 Obsidian Spaced Repetition (SR)**：
  - 阶梯列表卡：导出为标准 Markdown 列表，并添加 `<!-- lv-card: sequence -->` 注解；
  - 文档温故：导出为标准 Markdown 文件，并在 YAML Frontmatter 写入符合 Obsidian SR 规范的排期字段：
    ```yaml
    ---
    sr-due: 2026-11-23
    sr-interval: 7
    sr-ease: 250
    ---
    ```
- **导出至 `.lvcards` 生态分享包**：
  - 完整保留 `custom-lv-card-type: "sequence"` 与条目状态机元数据，跨电脑导入时 100% 保持阶梯展开特性。
