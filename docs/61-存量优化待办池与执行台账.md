## 1. 治理与执行规范

1. **缺陷分类分级**：
   - **直修类 (Immediate Fix)**：影响正常使用、异常未捕获、样式错位等，在当前批次内直接修复，不留隐患；
   - **入池类 (Queued Task)**：涉及底层事件结构、异步同步机制调整或跨模块验证的项，统一入池排期，在专门批次集中处理。
2. **四要素规范**：每条入池待办必须具备：
   - ① **问题描述**（含文件行号与复现步骤）；
   - ② **解决方案**；
   - ③ **成本预估**（整数：小 1 / 中 2 / 大 3）；
   - ④ **风险评估**。

### FIX-01：修复今日面板水蛭卡跳转打开文档时的未捕获异常隐患
- **位置**：`src/ui/dashboard.svelte:1311`
- **问题**：在今日仪表盘水蛭卡列表中点击「重写」直接调用 `openTab({ app: ctx.app, doc: { id: l.blockID, zoomIn: true } })`，若宿主环境异常或处于断网隔离环境，调用失败会抛出未捕获异常并导致控制台报错。
- **修复方案**：使用标准 try-catch 包裹 `openTab` 调用，并在异常时通过 `friendlyError(e, t)` 友好弹出思源原生消息通知，保证用户操作反馈闭环。
