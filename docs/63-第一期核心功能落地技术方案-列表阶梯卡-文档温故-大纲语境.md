## 二、 功能一：RemNote 风格列表阶梯展开卡（Sequence Progressive Card）

### 1. 数据契约与块属性规范
- **适用块类型**：
  1. 思源无序/有序列表（`NodeList`，子块为 `NodeListItem`）；
  2. 包含多个要点子块的超级块（`NodeSuperBlock`）。
- **块属性标识（存储于目标块自身，零正文污染）**：
  ```javascript
  {
      "custom-lv-card-type": "sequence",           // 标明为阶梯展开卡
      "custom-lv-seq-mode": "ordered",             // ordered: 顺序阶梯揭晓 | random: 乱序填空
      "custom-riff-title": "操作系统的 5 大特征是什么？" // 题干（若无属性问答，自动取列表前置段落）
  }
  ```
- **制卡快捷入口**：
  - 在列表项块菜单注入：`✦ 切换为阶梯展开列表卡`；
  - 斜杠命令支持：`/seq`、`/阶梯卡`。

### 2. 纯逻辑核心：`src/core/sequence-card.ts`
```typescript
export interface SequenceItem {
    index: number;
    id: string;
    rawHtml: string;
    cleanText: string;
    status: "hidden" | "active" | "revealed";
    markedCorrect?: boolean; // 用户标记的掌握状态（true: 正确, false: 遗漏）
}

export interface SequenceCardModel {
    cardId: string;
    blockId: string;
    questionTitle: string;
    items: SequenceItem[];
    revealedCount: number;
    totalCount: number;
    isFullyRevealed: boolean;
}

/**
 * 识别当前 HTML 或属性是否应当按阶梯列表卡呈现
 */
export function isSequenceCard(html: string, attrs?: Record<string, string> | null): boolean {
    if (attrs && attrs["custom-lv-card-type"] === "sequence") return true;
    return false;
}

/**
 * 从列表或超级块 HTML 中切分题干与多项阶梯条目（纯函数，Node 可单测）
 */
export function parseSequenceCard(
    html: string,
    customTitle: string = "",
    cardId: string = ""
): SequenceCardModel {
    if (!html) {
        return { cardId, blockId: "", questionTitle: customTitle, items: [], revealedCount: 0, totalCount: 0, isFullyRevealed: true };
    }

    let questionTitle = customTitle.trim();
    const items: SequenceItem[] = [];

    if (typeof document === "undefined") {
        // Node 纯逻辑单测环境下的正则表达式轻量解析回退
        return parseSequenceFastFallback(html, questionTitle, cardId);
    }

    const template = document.createElement("template");
    template.innerHTML = html.trim();
    const container = template.content.firstElementChild;

    if (!container) {
        return { cardId, blockId: "", questionTitle, items: [], revealedCount: 0, totalCount: 0, isFullyRevealed: true };
    }

    const blockId = container.getAttribute("data-node-id") || "";

    // 1. 若为 NodeList (ul / ol)
    if (container.getAttribute("data-type") === "NodeList" || container.classList.contains("list")) {
        const lis = Array.from(container.children).filter(el => 
            el.getAttribute("data-type") === "NodeListItem" || el.classList.contains("li")
        );
        lis.forEach((li, idx) => {
            const clone = li.cloneNode(true) as HTMLElement;
            clone.querySelector(".protyle-action")?.remove();
            items.push({
                index: idx,
                id: li.getAttribute("data-node-id") || `item-${idx}`,
                rawHtml: clone.innerHTML.trim(),
                cleanText: (clone.textContent || "").trim(),
                status: "hidden",
            });
        });
    } 
    // 2. 若为 NodeSuperBlock (sb)
    else if (container.getAttribute("data-type") === "NodeSuperBlock" || container.classList.contains("sb")) {
        const subBlocks = Array.from(container.children).filter(el => 
            el.hasAttribute("data-node-id") || el.classList.contains("p") || el.classList.contains("li")
        );
        if (!questionTitle && subBlocks.length > 0) {
            questionTitle = (subBlocks[0].textContent || "").trim();
        }
        const answerSubBlocks = subBlocks.length > 1 ? subBlocks.slice(1) : subBlocks;
        answerSubBlocks.forEach((sbChild, idx) => {
            const clone = sbChild.cloneNode(true) as HTMLElement;
            clone.querySelector(".protyle-action")?.remove();
            items.push({
                index: idx,
                id: sbChild.getAttribute("data-node-id") || `item-${idx}`,
                rawHtml: clone.outerHTML.trim(),
                cleanText: (clone.textContent || "").trim(),
                status: "hidden",
            });
        });
    }

    return {
        cardId,
        blockId,
        questionTitle: questionTitle || "请按序回忆以下各条要点：",
        items,
        revealedCount: 0,
        totalCount: items.length,
        isFullyRevealed: items.length <= 1, // 只有0或1项时自动判定为无需分步
    };
}

/**
 * 推进揭晓下一条（纯函数状态转移）
 */
export function advanceSequenceStep(model: SequenceCardModel): SequenceCardModel {
    if (model.isFullyRevealed || model.revealedCount >= model.totalCount) {
        return { ...model, isFullyRevealed: true };
    }
    const nextRevealedCount = model.revealedCount + 1;
    const updatedItems = model.items.map((item, idx) => {
        if (idx < nextRevealedCount) {
            return { ...item, status: "revealed" as const };
        }
        if (idx === nextRevealedCount) {
            return { ...item, status: "active" as const };
        }
        return { ...item, status: "hidden" as const };
    });

    return {
        ...model,
        items: updatedItems,
        revealedCount: nextRevealedCount,
        isFullyRevealed: nextRevealedCount >= model.totalCount,
    };
}

/**
 * 一键揭开全部
 */
export function revealAllSequence(model: SequenceCardModel): SequenceCardModel {
    return {
        ...model,
        revealedCount: model.totalCount,
        isFullyRevealed: true,
        items: model.items.map(item => ({ ...item, status: "revealed" as const })),
    };
}
```

### 4. 输入法守卫与快捷键防冲突（关键工程细节）
在全局或组件键盘监听中，必须增加以下严格守卫：
```typescript
function handleSequenceKeyDown(e: KeyboardEvent) {
    // 1. 中文输入法合成期绝对不响应空格揭晓
    if (e.isComposing || e.keyCode === 229) return;

    // 2. 焦点位于输入框、文本域或富文本编辑区时不响应
    const target = e.target as HTMLElement;
    if (target && (target.tagName === "INPUT" || target.tagName === "TEXTAREA" || target.isContentEditable)) {
        return;
    }

    if (e.code === "Space" || e.key === " ") {
        if (e.shiftKey) {
            e.preventDefault();
            model = revealAllSequence(model);
        } else if (!model.isFullyRevealed) {
            e.preventDefault();
            model = advanceSequenceStep(model);
        }
    } else if (e.code === "KeyR" || e.key === "r") {
        if (!e.ctrlKey && !e.metaKey) {
            e.preventDefault();
            model = { ...model, revealedCount: 0, isFullyRevealed: false };
        }
    }
}
```

### 2. 调度与排期核心：`src/core/document-review.ts`
```typescript
export interface DocReviewItem {
    docId: string;
    title: string;
    hpath: string;
    lastReviewDate: string;
    intervalDays: number;
    reps: number;
    ease: number;
    isDue: boolean;
    dueDiffDays: number;
}

/**
 * 计算文档下一次温故间隔（基于标准轻量 FSRS/SM-2）
 */
export function calculateDocNextSchedule(
    rating: 1 | 2 | 3 | 4, // 1: Again, 2: Hard, 3: Good, 4: Easy
    currentInterval: number,
    reps: number,
    ease: number
): { nextInterval: number; nextReps: number; nextEase: number } {
    if (rating === 1) {
        return { nextInterval: 1, nextReps: 0, nextEase: Math.max(1.3, ease - 0.2) };
    }
    const nextReps = reps + 1;
    let nextEase = ease;
    if (rating === 2) nextEase = Math.max(1.3, ease - 0.15);
    if (rating === 4) nextEase = ease + 0.15;

    let nextInterval = 1;
    if (nextReps === 1) nextInterval = rating === 2 ? 1 : (rating === 4 ? 4 : 2);
    else if (nextReps === 2) nextInterval = rating === 2 ? 3 : (rating === 4 ? 10 : 6);
    else {
        const factor = rating === 2 ? 1.2 : (rating === 4 ? nextEase * 1.3 : nextEase);
        nextInterval = Math.round(currentInterval * factor);
    }

    return { nextInterval: Math.min(365, Math.max(1, nextInterval)), nextReps, nextEase };
}

/**
 * 组装 SQL 查询所有已加入温故流的文档列表
 */
export function buildDocReviewQuerySql(): string {
    return `SELECT id, content, hpath, ial 
            FROM blocks 
            WHERE type = 'd' 
              AND ial LIKE '%custom-lv-note-review="true"%' 
            ORDER BY updated DESC LIMIT 200;`;
}
```

## 四、 功能三：RemNote 级大纲层级语境面包屑（Hierarchical Context Path）

### 1. 双通道大纲获取机制（内核 API 优先 + 单调栈兜底）
- **通道 1（推荐 · 极速 0ms）**：
  直接调用思源内核官方接口 `/api/block/getBlockBreadcrumb`：
  ```typescript
  export async function fetchKernelBlockBreadcrumbs(blockId: string): Promise<HeadingNode[]> {
      const resp = await kernelRead<Array<{ id: string; name: string; type: string; subType: string }>>(
          "/api/block/getBlockBreadcrumb",
          { id: blockId }
      );
      if (!Array.isArray(resp)) return [];
      return resp
          .filter(node => node.type === "h" || node.type === "d")
          .map(node => ({
              id: node.id,
              level: parseHeadingLevel(node.subType),
              title: cleanTitleText(node.name),
              sort: 0,
          }));
  }
  ```
- **通道 2（离线/单测兜底 · 单调栈重构）**：
  在单测或离线环境下，通过同根文档前置标题数组执行 `extractAncestorHeadingsByStack`。

### 2. 单调栈算法纯逻辑：`src/core/heading-hierarchy.ts`
```typescript
export interface HeadingNode {
    id: string;
    level: number; // 1 ~ 6 (对应 h1 ~ h6)
    title: string;
    sort: number;
}

export function parseHeadingLevel(subtype: string): number {
    const match = String(subtype ?? "").match(/h([1-6])/i);
    return match ? parseInt(match[1], 10) : 1;
}

export function extractAncestorHeadingsByStack(
    rawHeadings: readonly { id: string; subtype: string; content: string; sort: number }[],
    options: { maxDepth?: number } = {}
): HeadingNode[] {
    const maxDepth = options.maxDepth ?? 4;
    const stack: HeadingNode[] = [];
    const sorted = [...rawHeadings].sort((a, b) => a.sort - b.sort);

    for (const h of sorted) {
        const level = parseHeadingLevel(h.subtype);
        const title = String(h.content ?? "").replace(/<[^>]+>/g, "").trim();
        if (!title) continue;

        while (stack.length > 0 && stack[stack.length - 1].level >= level) {
            stack.pop();
        }

        stack.push({
            id: String(h.id),
            level,
            title,
            sort: h.sort,
        });
    }

    return stack.slice(0, maxDepth);
}
```

### 3. 面包屑呈现与双端自适应：`ReviewCardBreadcrumbs.svelte`
- **桌面端**：完整大纲路径平铺展示，点击任意标题节点精准调用思源 `openTab` 并在编辑器内高亮原标题；
- **移动端（≤680px）**：若大纲深度 > 2，自动省略折叠中间层级，仅展示末级与直接父标题（如 `... ❯ 背包问题 ❯ 0-1背包`），杜绝折行挤占卡面。

## 七、 避坑指南（Gotchas & Anti-Patterns）

1. **避坑 1：切忌直接用 `sort < cardSort` 查询平铺标题**  
   思源的 `sort` 是同级兄弟序号。若卡片在列表项内，其 `sort` 为 0，直接查询将查不到任何前置标题！必须通过内核原生 `/api/block/getBlockBreadcrumb`，或递归追溯顶层容器的 `docTopSort`。
2. **避坑 2：Svelte 5 语法严格一致性**  
   新组件全部使用 Svelte 5 的 `$props()`、`$state()` 和 `$derived()`，严禁写成 Svelte 4 废弃的 `export let`。
3. **避坑 3：移动端弹层与按钮防手势冲突**  
   阶梯列表打标按钮、全幅画布工具栏必须显式声明 `data-prevent-swipe="true"`，防止横滑切卡。
4. **避坑 4：避免内存泄漏**  
   在嵌入 `Protyle` 渲染长文时，组件卸载生命周期内必须显式调用 `protyleInstance.destroy()`。
