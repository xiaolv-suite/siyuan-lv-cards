- **调研日期**：2026-10-31
- **调研对象**：思源笔记 v3.8.9（本机 `D:/RJ/SiYuan`，内核 conf 与 stage 前端产物逐字符串枚举实测）
- **对照基准**：小驴闪卡 v0.225.0（`src/api/riff.ts` 包装层 + 各 UI 模块）

## 2. 本体设置页闪卡参数对照（conf.flashcard）

内核 `conf.flashcard` 实测值（隔离工作区 conf.json）与插件透出情况：

| 内核参数 | 本体默认 | 插件状态 |
| :--- | :--- | :--- |
| `newCardLimit` / `reviewCardLimit` | 20 / 200 | ⚠️ 未透出内核值；插件有自有目标层 `dailyNewTarget` / `dailyReviewTarget`（只约束插件侧计划与徽章，不改内核出队上限） |
| `mark` / `list` / `blockquote` / `callout` / `superBlock` / `heading` / `deck` | true×6 / deck=false | ✅ 等效能力齐备：插件制卡不依赖本体开关——块菜单/划词/标记扫描/图片遮挡/超级块模板直接以任意块入组（`deck` 型嵌套卡包本体默认关闭，插件用「卡组多选范围」替代） |
| `requestRetention` / `maximumInterval` / `weights`（FSRS 19 参） | 0.9 / 36500 / 默认权重 | ⚠️ 未透出；调度完全由内核按此参数执行，插件读取与展示复习结果但未提供调参界面 |
| `reviewMode` | 0 | ⚠️ 未透出（本体旧版复习模式残留键） |

**建议（后续批次）**：在插件设置中增加「内核调度参数」分区，经 `/api/setting/getConf` 读、内核 conf 写回（或以 `SIYUAN_E2E_ALLOW_SHARED` 同款谨慎策略引导用户到本体设置页），并显示当前生效值；低优先级——本体设置页已可调，插件侧展示当前 `requestRetention` 与权重摘要即可建立认知闭环。

## 3. 本体 UI 能力对照

| 本体能力 | 插件覆盖 |
| :--- | :--- |
| 块菜单「添加到卡包」（任意块） | ✅ 块菜单「制作闪卡」+ 快速制卡 + AI 制卡 + 标记扫描，通道更多 |
| `==挖空==` 自动成卡（mark 型） | ✅ 挖空表达模板 + 划词一键挖空（Ctrl+H）+ 多挖空 |
| 复习窗口（翻面/1–4 档评分/跳过） | ✅ 且增强：时间预算、收工原因、Cram 突击、错因归因、星标、成对配对练习、挑战模式 |
| 重置进度 | ✅ 管理器三类重置 |
| 卡包改名/删除 | ✅ 总览与卡库 |
| 到期徽章（Alt+0 顶栏） | ✅ 顶栏徽章 + 语义化角标（今日完成态/考试倒计时） |
| 复习记录随仓库同步 | ✅ 内核原生行为，不干预；插件数据（revlog/统计）走本地存储 |
| 本体**没有**的能力 | 小驴闪卡独有：AI 批量制卡与成本台账、单选/多选/判断/填空交互题、图片遮挡、可学性把关与一键拆卡、来源变更并排修卡与版本回退、复习热力图/留存曲线/负载预报、块属性镜像与《动态看板》活文档、考试倒排计划、材料收件箱、Anki 导入导出 |

## 4. 结论

1. **API 全覆盖**：16 个内核 riff 端点全部包装且经真机（隔离内核 43930）逐类验证可用；
2. **能力超集**：本体所有闪卡交互（含重置/跳过/改名/删除/范围复习）在插件中均有对应且更强入口；
3. **唯一缺口**：内核 FSRS 调参（requestRetention/weights/每日上限）未在插件内透出——不影响功能完整性（本体设置页可调），已记为后续增强建议；
4. 本轮制卡页强化（卡组选择创建流、上次卡组记忆、Ctrl+1/2/3、填入示例、字数统计、预览翻面）见 `docs/57` 第 8 节。
