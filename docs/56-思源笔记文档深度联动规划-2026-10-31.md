# 56 · 思源笔记文档深度联动规划（2026-10-31，基线 v0.224.0）

> **核心目标**：小驴闪卡作为长在思源笔记本体上的插件，不能把用户的学习过程锁在 `data/storage/petal/siyuan-lv-cards/*.json` 的私有黑盒里，也不能反过来把高频流水硬塞进笔记正文造成排版污染与同步风暴。
>
> **设计总则**：**“状态进块属性、关系走双向块引、产出落每日笔记與专题文档、高频流水留底层存储。”** 让所有学习内容在思源文档树、反向链接面板、关系图谱、原生数据库（Attribute View）与 SQL 嵌入块中全部可见、可查、可带走。

---

## 1. 现状盘点：哪些已经在文档里，哪些还锁在插件私有 JSON 里？

| 内容维度 | 当前在思源文档中的体现（v0.224.0） | 当前缺失的文档联动断点 |
|---|---|---|
| **卡片本体** | 原地挖空卡留在原文档；快速制卡、标记制卡、AI 制卡落在 `/小驴闪卡/快速制卡` 等独立文档 | 快速制卡、标记制卡、AI 制卡生成的新块**没有写入指向原文档的块引 `((id))`**，在原笔记的“反向链接”面板和关系图里看不到提炼出的卡片 |
| **卡片重点与诊断状态** | 仅 `memo`（助记便签）和 `custom-lv-dismissed`（归档）写入了块属性 | **星标收藏**（`starredCards`）、**水蛭疑难状态**（`leech`）、**遗忘错因**（`error-tags.json`）全在私有 JSON，思源编辑器、书签面板、SQL 嵌入块无法感知 |
| **卡片关联关系** | 仅保存在 `relations.json`（前置/对比/易混） | 未转化为思源原生块引 `((id "关联卡"))`，思源关系图无法呈现卡片间的知识网络 |
| **每日学习产出** | 仅手动点击“导出学习报告”时新建一篇孤立的 `/小驴闪卡/学习报告/<日期>` | 与思源用户最常用的 **Daily Note（每日笔记）零联动**；今天背了多少卡、哪几张卡忘了，在当天日记里毫无痕迹 |
| **待制卡收件箱 / 目标 / 考试** | 保存在 `inbox.json`、`learning-goals.json`、`exam-plans.json` | 无法在思源文档里以任务列表 `- [ ] ((id))` 查看待制卡材料，也无法在备考大纲文档里直接看到关联的学习进度 |

## 2. 思源三层原生载体设计（怎么让所有内容自然体现在文档里）

### 第一层：块属性镜像层（Block IAL Attributes · 零正文侵入，打通思源搜索/书签/数据库）

在不改动笔记正文一字一句的前提下，通过 `/api/attr/setBlockAttrs` 将卡片的关键学习状态同步到思源块属性：

1. **星标收藏 ↔ 思源块属性与原生书签**：
   - 点亮星标时同步写入 `custom-lv-starred="true"`；
   - 可选同步写入思源原生 `bookmark="⭐ 重点闪卡"`，让用户直接在思源左侧原生“书签”面板看到所有重点闪卡。
2. **水蛭疑难卡与遗忘次数 ↔ 块属性标记**：
   - 当卡片遗忘次数达到水蛭阈值（或状态变化）时，自动在源块写入 `custom-lv-leech="true"` 与 `custom-lv-lapses="<次数>"`；修卡重制后自动清除。
3. **最近错因与掌握状态 ↔ 块属性标记**：
   - 复习打标错因（如概念混淆、审题失误）时，同步写入 `custom-lv-error-reason="concept"`；
   - **直接价值**：用户可在任意思源文档中用一行原生嵌入块 `{{SELECT * FROM blocks WHERE ial LIKE '%custom-lv-leech="true"%'}}` 实时拉出全库疑难错题，无需点开插件也能在文档中维护错题。

---

### 第二层：双向块引与原位制卡层（Block Ref `((id "锚文本"))` · 打通反向链接面板与关系图谱）

思源最核心的灵魂是**块级双向链接**。只要建立了 `((blockID "锚文本"))`，思源的反向链接面板、悬浮预览和关系图谱就会全部自动生效：

1. **制卡落点双模式（原位挂接 vs 卡册归集+自动反链）**：
   - **模式 A · 原文档就地挂接**：从当前阅读文档触发快速制卡、标记制卡或 AI 制卡时，支持直接将生成的问答卡追加在当前选中块下方（或当前文档末尾的 `## 闪卡提炼` 章节下），卡片与原文天然同处一篇文档；
   - **模式 B · 独立卡册 + 自动来源反链**：若选择集中存入 `/小驴闪卡/快速制卡` 或 `/小驴闪卡/AI 制卡/<日期>`，写入卡片块时自动附带来源反链行（`> 来源：((sourceBlockID "原文档标题"))`）及块属性 `custom-lv-source-doc` / `custom-lv-source-block`。
   - **效果**：当用户在思源里阅读任何一篇笔记并打开右侧**反向链接面板**时，所有从这篇笔记派生出去的闪卡一目了然，悬停即可预览卡面。
2. **卡片语义关系（`relations`）文档化**：
   - 在卡片详情抽屉建立“易混对比 / 前置知识 / 补充示例”关系时，同步写入 `custom-lv-relations` 属性，并可选在卡片备注或关联行写入 `((targetBlockID "易混对比"))` 块引，使思源原生关系图能够直接渲染出知识卡片拓扑。

---

### 第三层：结构化文档层（Daily Note 每日笔记 + 活文档看板）

把分散在插件各处的“人可读产出、待办材料与周期复盘”真正落成思源文档：

1. **Daily Note（每日笔记）复习复盘联动**：
   - **触发方式**：复习完成屏（`ReviewSessionDone`）提供“写入今日 Daily Note”一键按钮，并在设置中支持“每日收工自动同步到今日笔记”；
   - **落盘机制**：调用思源原生 `/api/filetree/createDailyNote` 获取或创建今日日记，通过块属性 `custom-lv-daily-review="YYYY-MM-DD"` 查找当日复盘块——**若已存在则原地 `updateBlock` 更新，绝不重复堆叠**；
   - **体现在日记里的内容**：
     - 今日学习统计一句话摘要（已复习 $N$ 张、保持率、学习时长、连续打卡天数）；
     - **今日遗忘与重点卡片块引列表**：把本场评为“遗忘（Again）”或新标星的卡片，写成标准思源块引列表 `- ((blockID "题干摘要")) · 遗忘 2 次 · 错因：概念混淆`。
   - **双向效果**：
     - 日记里直接记录了今天真正没掌握的知识点，点块引即可跳回原卡；
     - 反过来，在原卡片的思源反向链接面板里，会自动留下一串按日期排列的“遗忘复盘轨迹”（哪天忘过、错因是什么，在文档反链里清清楚楚）。
2. **待制卡收件箱（Inbox）文档化双向同步**：
   - 在目标笔记本 `/小驴闪卡/待制卡收件箱` 维护一篇收件箱文档（通过 `custom-lv-doc="inbox"` 幂等定位）；
   - 用户在笔记里右键“加入材料收件箱”时，自动在该文档追加一条任务项 `- [ ] ((blockID "材料摘录摘要"))`；
   - 用户在插件收件箱完成制卡，或直接在思源文档里把任务项打勾 `- [x]`，两边状态自动对齐。
3. **学习目标 / 考试计划绑定思源文档 + 一键生成《闪卡动态错题本》**：
   - 支持把任意思源文档（如《高等数学备考大纲》）关联为学习目标或考试计划的主文档，一键向该文档写入/更新“备考掌握度与薄弱卡块引摘要块”；
   - 提供一键生成 `/小驴闪卡/闪卡动态看板与错题本` 文档，内置思源原生 SQL 嵌入块（自动汇总水蛭卡、星标卡、近期新增卡与待处理收件箱），即使完全不打开插件主面板，也能在思源文档树里直接浏览与管理。

## 3. 防污染、防冲突与性能边界（四条硬约束）

为了让“文档联动”成为加分项而不是打扰用户的负担，必须严格执行以下四条边界：

1. **高频机器流水不进文档**：
   - 每次按键评分的毫秒级流水（`revlog.json`）、本场会话瞬时游标（`session-state.json`）、AI 断点恢复与 Token 账本（`ai-jobs.json` / `ai-cost-ledger.json`）**严禁逐条写入思源文档**，避免触发思源高频文件监听、全文索引重建与云端同步冲突；文档里只体现**按日聚合的 Daily Note 复盘块**与**低频状态属性**。
2. **100% 幂等原地更新（不刷屏、不造重复块）**：
   - 无论是写入 Daily Note 的当日复盘块，还是收件箱文档条目、备考文档摘要块，一律使用唯一块属性（如 `custom-lv-daily-review="2026-10-31"`、`custom-lv-inbox-item="<blockID>"`）先查后写：同日多次复习只更新同一个块，绝不在用户日记末尾反复追加十几个重复段落。
3. **原笔记正文零侵入默认原则**：
   - 除非用户主动执行“挖空制卡”、“就地修卡”或选择“原文档内追加卡片”，否则插件对原业务笔记**只写块属性（IAL）与反向链接**，不篡改用户原有的段落文字与排版。
4. **分级可控开关**：
   - 在设置页提供“思源文档联动”分组开关：
     - `[默认开]` 制卡自动附带来源文档块引（`((id))`）与血缘属性；
     - `[默认开]` 星标、水蛭与错因状态同步至卡片块属性（`custom-lv-*`）；
     - `[可选开 / 完成屏一键触发]` 复习收工同步写入今日 Daily Note（含今日遗忘卡块引清单）；
     - `[可选开]` 待制卡收件箱同步维护 `/小驴闪卡/待制卡收件箱` 文档。

## 4. 分阶段实施路线建议（按投入产出比排序）

| 批次 | 落地内容 | 改完之后在思源文档里能看到什么变化 |
|---|---|---|
| **第一批（D1 · 块属性镜像与来源双链）** | ① 快速制卡、标记制卡、AI 制卡支持关联当前文档/选中块并自动写入 `((sourceID))` 反链与 `custom-lv-source-*` 属性，支持选“追加到当前文档”或“存入卡册”；<br>② 星标、水蛭、错因同步写入卡片块属性 `custom-lv-starred` / `custom-lv-leech` / `custom-lv-error-reason`；<br>③ 一键生成《闪卡动态错题本》原生 SQL 看板文档 | 打开任何一篇读过的笔记，右侧**反向链接面板**直接列出提炼出的所有闪卡；在思源里用原生 SQL 嵌入块或属性搜索就能直接拉出所有星标卡与水蛭疑难卡 |
| **第二批（D2 · Daily Note 每日笔记复盘与错题块引）** | ① 接入 `/api/filetree/createDailyNote`；<br>② 复习完成屏新增“写入今日 Daily Note”按钮（及自动同步开关），按日期幂等更新今日复习摘要与**今日遗忘卡 `((blockID))` 块引列表** | 每天背完卡，当天的 **Daily Note** 自动多出一块干净的复习复盘与错题块引；每张常忘卡片的反链面板里自动积累按日期排列的遗忘轨迹 |
| **第三批（D3 · 收件箱与目标/考试计划文档化）** | ① 材料收件箱双向同步 `/小驴闪卡/待制卡收件箱` 任务列表文档；<br>② 学习目标与考试计划支持绑定思源主文档并原地更新进度摘要块；<br>③ 卡片详情语义关系同步为块引 | 收件箱、学习目标、考试备考不再只是插件里的表单，而是文档树里活生生的任务列表与大纲文档，卡片关联在思源关系图谱中直接可见 |
