## 2. 常用操作命令

根目录已配置便捷 npm 脚本与双击启动文件：

```bash
# 1. 启动/检查隔离测试网页（自动脱离终端在后台运行）
pnpm run serve:isolated
# 或双击项目根目录的「启动隔离测试网页.bat」

# 2. 修改代码重新 build 后，一键热更新插件静态文件（免重启、免丢失笔记）
pnpm run serve:isolated:reload

# 3. 查看当前后台运行状态
node scripts/serve-isolated-web.mjs --status

# 4. 安全关闭后台隔离内核
pnpm run serve:isolated:stop

# 5. 彻底清空工作区并重新灌入干净演练数据
pnpm run serve:isolated:clean
```

## 7. 全卡型示例组装载与公式渲染缺陷修复

### 《闪卡类型全覆盖示例》文档与「全部卡型示例组」

`scripts/serve-isolated-web.mjs` 新增 `seedAllCardTypesDemo`：在隔离工作区自动生成《闪卡类型全覆盖示例》文档（含 14 类卡型清单说明）并灌入独立卡组「全部卡型示例组」，每类至少一张演示卡，幂等可重跑（文档已存在即跳过）：

1. 标准问答题（题面 + `==答案==`）；
2. 挖空题（一段话三处挖空）；
3. 超级块多段问答（`{{{col … }}}` 一题多问拆分）；
4. 双向卡（正反两张互为问答）；
5. 分隔符问答（`::` 语法）；
6. 图片遮挡卡（上传图标资产 + `lv-occlusion` 双遮挡框）；
7. 单选题（`custom-exam-type=single`，A–D 选项按钮 + 自动判定）；
8. 多选题（`custom-exam-type=multiple`，多选提交按钮）；
9. 判断题（`custom-exam-type=judge`，对/错 T/F 按钮）；
10. 填空题（`custom-exam-type=fill`，打字判定）；
11. 代码卡（行内代码芯片）；
12. 公式卡（行内 KaTeX）；
13. 表格卡（整表即卡面）；
14. 图片卡（题面 + 图片同块）。

关键实现约束（2026-10-31 实测）：思源 `appendBlock` 遇空行会把 Markdown 拆成多个独立块，只有首块被入组——因此**每张示例卡必须是单一块**（选项用软换行 `\n` 与题干同块、公式用行内 `$…$`、代码用行内反引号），否则选择题选项、表格、公式会与题干分离导致交互组件无法组装。

### 公式渲染缺陷修复（真实缺陷）

走查发现复习卡面与详情预览中 `$…$` 行内公式渲染为**空白**：内核 3.8.9 的 `getBlockDOM` 返回空壳 `<span data-type="inline-math" data-content="…" class="render-node">`，而旧宿主 API `window.siyuan.initKaTeX` 在网页端不存在。修复：
- 新增 `src/libs/math-render.ts`：幂等加载思源本体自带资产 `/stage/protyle/js/katex/katex.min.{css,js}`（零插件包体成本），遍历渲染全部空壳数学节点（行内 inline / 块级 displayMode），宿主资产缺失时静默降级；
- `ReviewCardBody.svelte` 数学检测正则扩展（补齐 `data-type="inline-math"` 等内核令牌）并接入补渲染；`card-detail.svelte` 详情预览同步接入；
- 新增 `tests/math-render.spec.ts` 5 项单测（令牌检测、行内/块级渲染、已渲染跳过、无 KaTeX 降级、空容器）；
- 实测：公式卡 `f(x)=1/(σ√2π)·e^{-(x-μ)²/2σ²}` 以 KaTeX 分数与指数完整渲染。

### 图标测试基线同步

`tests/kit-basics.spec.ts` 的 LvIcon 断言随 R57 空心图标体系更新（swap 路径断言改为 `M20 7H4`，并注明单测环境走 24×24 Lucide 空心兜底路径）。全套 254 文件 / 2075 项单测通过。

## 8. R58 制卡页专项强化与「选择卡组选不了」修复

1. **修复空库死状态（用户实测卡点）**：工作区没有任何卡组时，卡组下拉原被 `disabled` 渲染成不可用空框、提示语不引导且无刷新入口，用户观感即「选不了」；现改为——有卡组时下拉 + 标题显示数量「选择卡组（N）」+ 常驻刷新按钮；空库时不再渲染死下拉，直接显示创建输入框并自动聚焦，提示「当前还没有卡组：在上方输入名称，制卡时会自动创建并选中」，仅凭一个名称即可完成首张卡；
2. **上次卡组记忆**：新增设置项 `lastQuickCardDeck`，打开制卡页自动预选上次成功制卡的卡组（`initialDeckID` + `onDeckUsed` 回调，实测落盘 `settings.json`）；
3. **模板快捷键 Ctrl+1/2/3**：在问答/挖空/超级块之间切换，不改已输入内容（按钮 aria-keyshortcuts 与 title 同步标注）；
4. **一键填入示例**：内容为空时显示「填入示例」按钮，按当前模板给出对应示例草稿（问答/挖空含 `____`/超级块多段），有内容时自动隐藏、绝不覆盖用户草稿；
5. **字数统计**：问题/答案标签栏实时显示「N 字」，超过 60/120 字转警示色（与可学性把关联动）；
6. **预览点击翻面**：卡面预览支持点击/回车/空格翻面查看答案（`aria-pressed` 状态化），与右上「查看答案」按钮等效；
7. **无障碍修正**：带 `title` 提示的按钮显式补 `aria-label`（浏览器会把 title 当作可访问名，导致「填入示例」被读成整段提示语），预览面以 `aria-label="卡面预览"` 与标题栏按钮区分；
8. **测试**：`tests/quick-card-studio.spec.ts` 新增 5 项（空库创建流/卡组记忆/示例填充/快捷键/预览翻面），全套 254 文件 / 2080 项单测通过，真机（43930 + 实机部署）逐项实测通过。
